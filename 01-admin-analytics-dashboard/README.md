# Admin Analytics Dashboard

A modern, responsive admin dashboard upgraded from a vanilla HTML/CSS/JavaScript dashboard into a React + TypeScript application.

## Features

- React + TypeScript component architecture
- Tailwind CSS
- Recharts analytics visualization
- Responsive sidebar/navigation
- Dark/light mode with localStorage persistence
- KPI cards and trend indicators
- Revenue and user analytics chart
- Searchable activity table
- Status filtering
- Client-side pagination
- Notifications dropdown
- Responsive mobile layout
- Loading/empty-friendly UI patterns
- Accessible button labels and semantic structure

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Recharts
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Portfolio note

This project currently uses mock data. API/backend integration can be added later without changing the core UI architecture.
